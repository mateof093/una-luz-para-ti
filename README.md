# Una luz para ti

Una experiencia interactiva creada con recuerdos, fotografías, cartas y música. Cada estrella del matapalo conserva una luz importante en la vida de Gaby.

## Desarrollo local

Requiere Node.js 22.13 o superior.

```bash
npm ci
npm run dev
```

## Comprobaciones

```bash
npm run lint
npm test
npm run build:pages
```

## Publicación

El flujo de GitHub Actions genera una exportación estática y la publica automáticamente en GitHub Pages cuando se actualiza la rama `main`.

> Este repositorio contiene fotografías, audios y cartas personales compartidos con autorización para esta experiencia.
